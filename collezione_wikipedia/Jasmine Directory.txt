Jasmine Directory è una web directory editata manualmente che fornisce siti web categorizzati per tema e regione. La directory offre una gamma di 13 categorie tematiche ed una categoria regionale, con risorse suggerite dagli utenti ed accuratamente verificate.  Jasmine Directory contiene anche un blog in cui gli utenti possono trovare un elenco delle migliori web directories, consigli di marketing per le piccole imprese e informazioni sulla storia dei computer.
Gli editori di Jasmine Directory manualmente aggiungono risorse all'indice (il 90% degli elenchi di Jasmine Directory sono stati aggiunti manualmente, secondo il co-fondatore Robert Gomboș). I proprietari di siti web possono anche proporre i propri siti web per la revisione pagando una tassa; tuttavia, l'inclusione non è garantita se le risorse suggerite non sono conformi alle linee guida redazionali. A causa della discrezione editoriale coinvolta nel processo di quotazione, i motori di ricerca trovano le inserzioni in "directories di qualità" come citazioni valutate. I proprietari di siti web riportano che inviare i loro siti alle web directories può essere una procedura utile.
